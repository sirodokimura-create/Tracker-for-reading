# Tracker-for-reading
Приложение "Трекер для чтения"
1. Скачайте или нажмите на файл Setup Читалка.txt
2. В файле находится две ссылки на гугл диск и яндекс диск
3. Скопируйте ссылку и вставьте её в браузере
4. Откроется файл который необходимо скачать
5. После того как скачаете установщик нажмите на него двойным кликом мыши
6. Запустится установщик который установит приложение "Читалка"
